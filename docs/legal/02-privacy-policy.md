# 개인정보 처리방침

**버전** 1.0 (검토 대기) · **시행일** {{시행일}}

{{운영주체}}(이하 "회사")는 {{서비스명}}(이하 "서비스")을 제공하면서 이용자의
개인정보를 소중히 다룹니다. 이 서비스는 **건강에 관한 정보를 다루므로, 그 정보는
개인정보보호법상 민감정보에 해당합니다.** 회사는 이를 일반 개인정보와 구분하여
별도의 동의를 받고 처리합니다.

## 1. 수집하는 개인정보 항목

### 1-1. 계정 정보 (필수)

| 항목 | 수집 시점 |
|---|---|
| 이메일 주소 | 회원가입 시 |
| 비밀번호 | 회원가입 시 (암호화하여 저장, 회사는 원문을 알 수 없음) |

### 1-2. 프로필 정보 (선택)

| 항목 | 이용 목적 |
|---|---|
| 표시 이름 | 화면 표시 |
| 출생연도 | 연령별 참고범위 적용 |
| 성별 | 성별 참고범위 적용 |
| 키 | 체질량지수(BMI) 자동 계산 |
| 시간대 | 하루 집계·복약 알림 시각 계산 |
| 주간 운동 목표 시간 | 목표 달성률 표시 |

**입력하지 않아도 서비스를 이용할 수 있습니다.** 다만 해당 조건이 붙은
참고범위는 적용되지 않습니다.

### 1-3. 건강정보 (민감정보 — 별도 동의)

`docs/legal/03-sensitive-health-data.md` 참고.

### 1-4. 서비스 이용 과정에서 자동 수집·생성되는 정보

| 항목 | 수집 시점 | 목적 |
|---|---|---|
| 접속 기기 정보(User-Agent) | 동의 시, 알림 구독 시 | 동의 이력 증빙, 알림 구독 관리 |
| 알림 구독 정보(브라우저가 발급한 주소와 암호화 키) | 복약 알림을 켤 때 | 알림 발송 |
| 이용자가 등록한 음식 이름 | 식단 기록 시 | 다음 기록 시 재사용 |

**주민등록번호 등 고유식별정보는 수집하지 않습니다.**
**결제 정보는 수집하지 않습니다.**

## 2. 개인정보의 처리 목적

1. 회원 식별 및 인증
2. 이용자가 기록한 건강 데이터의 저장·정리·표시
3. 이용자 본인에 대한 지표 추세 및 주간 요약 제공
4. 복약 알림 발송 (이용자가 켠 경우에만)
5. 건강검진 결과지 자동 판독 (이용자가 동의하고 이용하는 경우에만)
6. 법령상 의무 이행 및 분쟁 대응

**회사는 위 목적 외로 개인정보를 이용하지 않으며, 이용자에게 광고를 위한
프로파일링을 하지 않습니다.**

## 3. 개인정보의 보유 및 파기

### 3-1. 보유 기간

**회원 탈퇴 시 즉시 파기합니다.** 별도의 보유 기간을 두지 않습니다.

법령에 따라 보존 의무가 있는 경우 그 기간 동안 분리 보관합니다.
(현재 이 서비스에는 해당 사항이 없습니다.)

### 3-2. 파기 절차 및 방법

계정 삭제 시 다음이 순서대로 일어납니다.

1. 데이터베이스의 이용자 계정 행을 삭제하면, 이에 연결된 **모든 테이블의
   기록이 함께 삭제**됩니다 (프로필, 동의 이력, 건강 수치, 수면, 복약,
   식단, 운동, 검진, 알림 구독).
2. 업로드한 검진 결과지 원본 파일을 저장소에서 삭제합니다.
3. 1과 2 사이에 오류가 발생하는 경우에 대비하여, 삭제 대상 파일 경로를
   내부 정리 목록에 남기고 **정기 배치가 재확인하여 삭제**합니다.

전자적 파일은 복구할 수 없는 방법으로 삭제합니다.

또한 이용자가 **개별 검진 기록을 삭제하면**, 그 검진에서 확정된 수치도
함께 삭제됩니다.

## 4. 개인정보 처리의 위탁

회사는 서비스 제공을 위해 아래와 같이 개인정보 처리를 위탁하고 있습니다.

| 수탁자 | 위탁 업무 | 처리하는 정보 | 보관 위치 |
|---|---|---|---|
| Supabase, Inc. | 데이터베이스·인증·파일 저장 운영 | 이 방침에 기재된 정보 전부 | {{Supabase_리전}} |
| Vercel Inc. | 애플리케이션 호스팅 | 요청 처리 과정에서 경유하는 정보 | {{Vercel_리전}} |
| Anthropic PBC | 검진 결과지 자동 판독 | 업로드한 결과지 파일 | 미국 |
| 브라우저 푸시 서비스 사업자<br>(Google LLC, Apple Inc., Mozilla 등) | 복약 알림 전달 | 알림 구독 주소, **암호화된** 알림 내용 | 각 사업자 정책에 따름 |

회사는 위탁계약 시 개인정보의 안전한 관리에 관한 사항을 계약에 반영하고
수탁자를 감독합니다. 수탁자나 위탁 업무가 변경되는 경우 이 방침을 통해
공개합니다.

### 4-1. 개인정보를 포함하지 않는 외부 호출

음식 검색 시 식품의약품안전처 공공 API 를 호출합니다. 이때 **전달되는 것은
검색어뿐이며, 이용자를 식별할 수 있는 정보나 접속 IP 는 전달되지 않습니다.**
(회사 서버가 대신 호출합니다.)

## 5. 개인정보의 국외 이전

검진 결과지 자동 판독을 이용하는 경우, 결과지 파일이 미국으로 이전됩니다.
자세한 내용과 동의 절차는 `docs/legal/04-llm-processing.md` 를 참고하십시오.

**이 기능에 동의하지 않아도 서비스를 이용할 수 있습니다.** 검진 수치를 직접
입력하는 방식으로 동일한 기능을 사용하실 수 있습니다.

> {{Supabase_리전}} · {{Vercel_리전}} 이 국외인 경우, 해당 사항을 이 절에
> 추가로 기재하고 별도 동의를 받아야 합니다. — `OPERATOR_FIELDS.md` 참고

## 6. 개인정보의 제3자 제공

회사는 이용자의 개인정보를 제3자에게 제공하지 않습니다.

다만 법령에 근거하여 수사기관 등이 적법한 절차에 따라 요구하는 경우에는
그러하지 아니합니다. 이 경우 법령이 허용하는 범위에서 이용자에게 알립니다.

## 7. 정보주체의 권리와 행사 방법

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

| 권리 | 행사 방법 |
|---|---|
| 열람 | 서비스 내 **기록**·**검진**·**리포트** 화면에서 확인 |
| 정정 | 각 기록 화면에서 직접 수정 |
| 삭제 | 각 기록 화면에서 개별 삭제, 또는 **설정 → 계정 삭제**로 전체 삭제 |
| 동의 철회 | **설정 → 동의 현황**에서 선택 동의 철회. 필수 동의 철회는 계정 삭제로 처리 |
| 처리 정지 | {{대표이메일}} 로 요청 |

법정대리인이나 위임을 받은 대리인을 통해서도 행사할 수 있습니다. 이 경우
개인정보보호법 시행규칙 별지 제11호 서식의 위임장을 제출해 주십시오.

회사는 요청을 받은 날부터 **10일 이내**에 처리하고 결과를 알립니다.

## 8. 개인정보의 안전성 확보조치

| 조치 | 내용 |
|---|---|
| 접근 통제 | 데이터베이스 전 테이블에 행 단위 보안 정책을 적용하여, **이용자는 자신의 데이터에만 접근할 수 있습니다.** |
| 파일 보호 | 검진 결과지는 비공개 저장소에 보관하며, **10분 후 만료되는 일회성 주소**로만 열람할 수 있습니다. |
| 최소 권한 | 내부 처리 함수의 실행 권한을 최소화하여, 다른 이용자의 정보를 역으로 추정할 수 있는 경로를 차단했습니다. |
| 암호화 | 전송 구간은 HTTPS 로 암호화하며, 저장 데이터는 저장소 수준에서 암호화됩니다. 비밀번호는 복호화할 수 없는 방식으로 저장됩니다. |
| 알림 내용 보호 | 복약 알림 내용은 종단간 암호화되어 발송되며, 전달 사업자는 내용을 읽을 수 없습니다. |
