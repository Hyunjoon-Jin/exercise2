| 문서 | 파일 | 동의 구분 | 상태 |
|---|---|---|---|
| 서비스 이용약관 | `01-terms-of-service.md` | 필수 | 🟡 검토 대기 |

**현재 DB 에 들어 있는 것은 `1.0-draft` 이며, 위 문서가 아닙니다.**
여기 문서는 검토용 재작성 초안입니다. 검토가 끝난 뒤 `publish.sql` 로 게시합니다.

DB 의 초안을 지금 교체하지 않는 이유: 게시하면 전 이용자가 재동의 대상이 됩니다.
검토 후 문안이 또 바뀔 텐데 그때마다 재동의를 받게 하면 이용자에게 부담입니다.

## 이 초안이 이전 초안과 다른 점

기존 `1.0-draft` 는 문서당 3~5문장이었고, 법정 필수 기재사항 다수와 **코드가
실제로 하는 일 일부가 빠져 있었습니다.**

검토 결과와 근거는 [`../LEGAL_REVIEW.md`](../LEGAL_REVIEW.md) 에 있습니다.
특히 §2 는 코드를 읽어야만 보이는 항목이라, 문서만 보고는 발견할 수 없습니다.

## 절차

1. [`../LEGAL_REVIEW.md`](../LEGAL_REVIEW.md) 의 §4 항목을 변호사와 확정
2. [`OPERATOR_FIELDS.md`](OPERATOR_FIELDS.md) 의 `{{ }}` 를 실제 값으로 교체
3. 변호사 검토 반영
4. `publish.sql` 을 `supabase/migrations/0010_consent_documents_v1.sql` 로 옮겨 적용

## 문서를 고칠 때

- **DB 의 기존 행을 수정하지 마십시오.** 이용자가 실제로 동의한 문안이 사라져
  동의 이력이 근거로 쓸 수 없게 됩니다.
- 항상 옛 버전을 `retired_at` 으로 내리고 새 버전을 추가하십시오.
- 본문은 평문으로 저장·렌더링됩니다. HTML 은 동작하지 않습니다 — 문서 편집이
  XSS 통로가 되지 않도록 의도한 것입니다 (`src/components/legal-document.tsx`).
