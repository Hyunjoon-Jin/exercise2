# 운영자가 채워야 할 항목

`docs/legal/` 의 초안에는 `{{ }}` 로 표시된 자리가 있습니다. 제가 지어낼 수 없는
사실들입니다 — **추측해서 채우면 그 자체가 허위 고지가 됩니다.**

## 필수

| 자리표시자 | 설명 | 예 |
|---|---|---|
| `{{서비스명}}` | 서비스 명칭 | 건강기록 |
| `{{운영주체}}` | 상호 또는 개인 사업자명. 법인이면 법인명 | ○○ 주식회사 |
| `{{대표자}}` | 대표자 성명 | 홍길동 |
| `{{사업자등록번호}}` | 사업자등록번호 | 000-00-00000 |
| `{{주소}}` | 사업장 주소 | 서울특별시 … |
| `{{대표이메일}}` | 문의 접수 이메일 | support@example.com |
| `{{보호책임자_성명}}` | 개인정보 보호책임자 | 홍길동 |
| `{{보호책임자_직책}}` | 직책 | 대표 |
| `{{보호책임자_연락처}}` | 전화 또는 이메일 | privacy@example.com |
| `{{시행일}}` | 문서 시행일 | 2026-09-01 |
| `{{서비스URL}}` | 서비스 주소 | https://example.com |

개인 개발자가 사업자 등록 없이 운영한다면 사업자등록번호 항목은 빼고, 성명과
연락 가능한 이메일은 반드시 있어야 합니다.

## 인프라 리전 — 문서 내용이 바뀝니다

| 확인할 것 | 왜 |
|---|---|
| Supabase 프로젝트 리전 | 국외면 **모든 개인정보가 상시 국외 저장**됨 |
| Vercel 배포 리전 | 위와 같음 |

**서울 리전(`ap-northeast-2`)이면** — 처리방침의 수탁자 표에 "국내"로 적으면 끝납니다.

**국외 리전이면** — 전 이용자를 대상으로 한 국외 이전 고지·동의가 필요합니다.
지금 스키마의 `consent_kind` enum 에는 해당 항목이 없으므로 **enum 추가
마이그레이션이 필요합니다.** 이 경우 알려 주시면 스키마와 온보딩 화면까지
같이 작업하겠습니다.

> 권고: 가능하면 서울 리전. 민감정보 서비스에서 국외 저장은 설명 부담이
> 계속 따라옵니다.

## Anthropic 확인 사항

`docs/legal/04-llm-processing.md` 의 보유·파기 문구는 **확인 전까지 비워 두었습니다.**
기존 초안은 "처리 완료 후 즉시 파기, 모델 학습에 이용되지 않음"이라고 단정하고
있었는데, 확인 없이 단정한 고지는 사실과 다를 경우 그 자체로 문제가 됩니다.

확인할 것:

1. 상업적 이용 조건에서 API 입력이 모델 학습에 사용되지 않는지
2. 신뢰·안전(Trust & Safety) 목적의 보관 기간이 실제로 얼마인지
3. 개인정보 처리 부속 계약(DPA) 체결 가능 여부
4. 고지에 넣을 이전받는 자의 연락처

## 정책 결정

| 결정할 것 | 선택지 | 기본 초안 |
|---|---|---|
| 만 14세 미만 | 가입 차단 / 법정대리인 동의 | **가입 차단** (가장 단순) |
| 동의 이력 탈퇴 시 처리 | 함께 파기 / 분리 보존 | **함께 파기** (현재 코드 동작) |
| 서비스 종료 시 데이터 반출 | 제공 / 미제공 | **30일 전 공지 + 반출 기간 제공** |

법정대리인 동의나 동의 이력 분리 보존을 택하면 **코드 작업이 추가로 필요합니다.**
